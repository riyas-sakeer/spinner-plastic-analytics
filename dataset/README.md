# 📋 Project Dataset

## File
`Spinner_Datasets_Final_v2.xlsx`

## 10 Sheet Structure

| Sheet | Contents | Period |
|-------|----------|--------|
| Sales Data | Monthly product-wise sales (₹) | 2022–2025 |
| Sales Data Unpivoted | Long format for Power BI | 2022–2025 |
| Cost of Production | Cost breakdown by product | 2022–2025 |
| Gross Margin Analysis | Product gross margin (₹ and %) | 2022–2025 |
| Inventory Data | Stock levels, reorder, holding days | 2022–2024 |
| Region Sales | District-wise index and % share | 2024 |
| Profit & Loss | P&L account data | FY 2020–2023 |
| Balance Sheet | Balance sheet data | FY 2020–2023 |
| Seasonal Trend | Monthly sales index | Annual |
| ABC Classification | ABC category, days, value share | 2022–2024 |

## Key Facts
- Base Sales FY 2020: ₹35 Crores (actual from company)
- Annual Growth Rate: 5% (company stated)
- 9 product categories · 14 Kerala districts
- Manufacturing (95% revenue) and Trading (5% revenue) segments

## Source
Primary data collected from Spinner Plastic Industries Limited, Thrissur.
