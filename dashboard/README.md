## About
An 8-tab interactive dashboard built with HTML, CSS, and Chart.js
styled exactly like Microsoft Power BI Desktop.

## Dashboard Tabs

| Tab | Content |
|-----|---------|
| 📊 Overview | 5 KPI cards · Sales line · Product pie · Insight box |
| 📈 Sales Analysis | Monthly trend · Stacked bar · Product ranking |
| 📦 Inventory & ABC | ABC table · Holding period · Turnover ratio |
| 💹 Gross Margin | Margin by product · Mfg vs Trading · Trend |
| 🗺️ Regional Sales | District table · Region pie · Status chart |
| 💰 Financial | P&L trend · Expense breakdown · Margin % |
| 🏦 Balance Sheet | Assets vs Liabilities · Loan trend |
| 🌦️ Seasonal Demand | Monthly index grid · Peak vs off-peak |

## File

## How to Use
1. Click the live link above in **Google Chrome**
2. Click any tab to switch between analysis pages
3. Hover over charts for detailed tooltips
4. Press **Ctrl + P** to print/save any page as PDF
